# MJ FTE

> Tera system, meri zimmedari.

Premium marketing and documentation website for [MJ FTE](https://github.com/syed-mujtaba-stack/mj-fte), an open-source Windows disk cleaner and system analyzer CLI agent written in Python.

## Run locally

```bash
pnpm install
pnpm dev
```

The site includes:

- `/` — product landing page
- `/docs` — long-form documentation
